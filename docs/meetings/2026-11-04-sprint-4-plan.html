The test plan and the code review are two separate items

Test plan (VV7, #109 and #110): we write the tests the plan lists, so the plan describes tests that exist and pass. The 13 placeholder tests (it.todo) in server/src/__tests__/taskts.test.ts are most of what is left.

Code review (VV10, #111 to #116): we read the code together and record what we find. The review looks at the tests too, so #111 depends on #109 and #110.

One does not replace the other. Both are graded.
