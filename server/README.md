# Server

Empty on purpose.

The prototype phase has no backend — all data is hardcoded in
`client/src/data/semester.ts`. This directory is scaffolded so the monorepo
mirrors the CS 262 sample layout, and so phase 2 has somewhere to land.

## What goes here later

- Express app
- Postgres (via Supabase) for courses, tasks and effort estimates
- The Moodle calendar subscription poller
